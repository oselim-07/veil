Veil

Keeps personal and health data out of your AI coding agent, with a report of what was hidden.

Download View on GitHub

The problem

AI coding agents run commands and read the output. That output can contain patient names, insurance numbers, IBANs, emails and passwords. Once it is in the agent's context, it has left your machine. Teams that handle health data in Europe have to follow the principles of data minimisation and data protection by design, but nothing sits between the terminal and the agent to help with that.

What Veil does

Hides sensitive data

Emails, IBANs, insurance IDs, dates, phone numbers and passwords are replaced with placeholders.

Wraps any command

veil run -- cat patient.txt runs the command and cleans the output. The exit code is preserved.

Audit report

--report shows how many items of each type were hidden. Counts only, never the data.

Your own rules

A veil.toml file adds names and custom ID formats, such as your clinic's patient numbers.

Demo (fake data)

Input:

Patient Max (PAT-123456), contact Anna Müller, born 12.03.1985, mail max@clinic.de

Command:

veil run --report -- cat patient.txt

What the agent sees:

Patient [REDACTED:name] ([REDACTED:patient_id]), contact [REDACTED:name], born [REDACTED:date], mail [REDACTED:email]
--- veil report ---
email: 1
date: 1
patient_id: 1
name: 2

Who it is for

Health-tech startups, clinics and digital health teams in Europe (especially DACH) that use AI coding agents on projects touching personal data. Typical users: developers, data engineers and the people responsible for data protection in those teams.

How Veil reaches its users

Open source on GitHub, short posts and demos for developers and health-tech communities, and practical guides on keeping personal data out of AI tools. Early users give feedback on rules for their own data formats.

Limits (please read)

Veil reduces risk but does not guarantee that nothing sensitive gets through. It uses pattern matching and a list of names you provide, so it can miss unusual formats. It hides all dates, not only birth dates. It is not legal advice and does not make a team compliant with GDPR or any other regulation. Test with fake data only.

Roadmap

JSON report export, a hook for supported coding agents, and more rule packs for European data formats.
